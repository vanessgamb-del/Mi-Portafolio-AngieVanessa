Aerolinea Api

La Aerolinea API es un backend RESTful desarrollado en Java con Spring Boot 3.x, estructurado en una arquitectura limpia por capas que separa controladores, servicios, DTOs y repositorios. Utiliza Spring Data JPA e Hibernate para mapear de forma automática los modelos de objetos hacia una base de datos relacional en PostgreSQL, administrada visualmente mediante pgAdmin 4..
